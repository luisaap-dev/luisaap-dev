## Sobre mí

Desarrollador Web Full Stack y Técnico Informático con más de una década en el sector IT. Combino el desarrollo de aplicaciones web modernas con la administración de sistemas, lo que me permite llevar un proyecto desde el código hasta el servidor en producción.

- 🔭 Actualmente desarrollo aplicaciones web como **freelance** con React, TypeScript, Django y Node.js
- ☁️ Despliego y administro infraestructura cloud: **OVHcloud, CloudPanel, Plesk, Linux VPS**
- 🛒 Experiencia en **comercio electrónico** e integración de pasarelas de pago y TPV
- 🌱 Ahora mismo profundizando en TypeScript y arquitecturas Full Stack
- 💬 Pregúntame sobre React, WordPress, despliegues en VPS o configuración DNS
- 📫 Disponible para proyectos freelance y nuevas oportunidades
